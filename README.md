# Thermal Power Plant Performance Dashboard

## Project Overview

This project is an interactive Power BI dashboard developed to monitor and analyze the operational performance of thermal power plants. It provides insights into plant efficiency, fuel consumption, electrical output, steam parameters and auxiliary power.

## Objective

To provide a comprehensive view of thermal power plant performance and help identify operational trends, efficiency differences and opportunities for improving energy utilization.

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Data Visualization

## Key Performance Indicators (KPIs)

* Average Auxiliary Power
* Average Condenser Pressure
* Average Efficiency
* Average Steam Temperature
* Average Steam Pressure
* Total Electrical Output
* Total Fuel Input

## Dashboard Features

* Plant-wise efficiency analysis
* Boiler-type performance comparison
* Fuel-type analysis
* Region-wise filtering
* Ownership-based analysis
* Electrical output vs. fuel input analysis
* Steam temperature and pressure monitoring
* Interactive slicers and visualizations

## Key Insights

* Compared the average efficiency of different thermal power plants.
* Analyzed auxiliary power consumption across boiler types.
* Evaluated the relationship between fuel input and electrical output.
* Compared steam temperature and pressure performance.
* Enabled analysis by region, fuel type, boiler type and ownership.
